뭐보뇽 Tester Beta v2 설치

  1. 받은 ZIP의 SHA256을 확인한 뒤 모두 압축 풀기를 선택하세요.
  2. 집중 세션을 끝내고 앱과 Chrome을 정상 종료하세요. Mobonyong-Tester-Beta-v2-Windows-x64-setup.exe를 실행하면 Chrome 연결 구성요소도 함께 등록됩니다. 설치 파일은 미서명이며, 학교나 회사 정책에 막히면 담당자에게 문의하세요.
  3. Chrome에서 chrome://extensions를 열고 개발자 모드의 압축해제된 확장 프로그램을 로드합니다로 ZIP의 extension 폴더를 선택하세요. 확장 버전은 0.3.6, ID는 ohajfkkemocajnjlbnogdmoominkejci입니다. 사용 중 폴더를 옮기지 마세요.
  4. 확장 팝업에서 관측을 켜고, 시작 메뉴에서 Mobonyong Tester Beta를 엽니다. 앱의 감지·AI 설정에서 Windows 활동 감지와 YouTube 로컬 관측에 각각 동의하면 관측할 수 있습니다. AI 판단은 별도 동의가 필요하며, 동의 시 작업명과 영상 제목·ID가 서버로 전송될 수 있습니다.
  5. 집중할 일을 한 줄로 입력하고 평소대로 사용하세요. 이 판의 Windows 무입력과 YouTube 개입은 1·5·10분 기준입니다. YouTube는 AI 판단 뒤 유효하게 관측된 재생 시간만 셉니다.

0.3.6-r1에서 업데이트

새 설치판의 내부 버전은 0.3.7입니다. 기존 Tester Beta와 같은 Windows 계정·설치 경로에서 업데이트하고, 앱 데이터 삭제를 선택하지 마세요. 기존 동봉 확장이 연결되어 있다면 같은 ID의 확장을 계속 쓸 수 있습니다.

문제가 있으면 연결 문제 해결을 확인하세요. 사용 소감은 피드백 참여 안내를 참고하세요.
