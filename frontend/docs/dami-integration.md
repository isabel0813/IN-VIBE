# 다미 UI 통합

기능 기준은 `feat/unified-focus-flow`의 `7ea036a`, 디자인 기준은 `origin/design/clean-home`의 `e901c12`이다. 통합 브랜치는 `feat/dami-ui-integration`이다. 원래 작업 폴더의 미커밋 리뷰 4개는 원본에 보존하고 이 브랜치에 포함하지 않았다.

## 선택적으로 반영한 변경

- 밝은 테마, 홈 레이아웃, 메뉴 서랍, 아이콘과 `annyong.png`, `ultimate.png`를 반영했다.
- 최신 `useCloudController`를 계속 한 번만 마운트한다. 홈·설정·메뉴 이동은 세션을 다시 만들지 않는다.
- 디자인 브랜치의 `/tasks`, `/plan` 초기 로드와 기본 일정 메뉴는 가져오지 않았다. 기존 API·작업 데이터·선택형 이전 화면은 유지한다.
- 디자인 브랜치의 `CloudSession.tsx` 전체와 localStorage 기반 영상 저장 코드는 가져오지 않았다. 단계 정보도 기존 메모리와 BroadcastChannel로 공유한다.
- 무응답에 대한 자동 인정, 자동 피드백, `answer: none` 전송은 없다. 사용자 버튼 응답만 질문을 종료한다.
- 궁극기는 현재 한 줄 집중 화면을 연다. 종료·일시정지·동의 철회 시 원래 전체화면 상태로 복원한다.

## 1·5·10분 기준

AI가 `ask`로 판단한 영상에 한해, 보이고 재생되는 관측 구간을 누적한다. 같은 영상은 한 번만 AI에 묻는다. 1분에 첫 질문, 5분에 추가 확인 문구, 10분에 궁극기와 Windows 전체화면을 표시한다. 첫 두 단계는 기존 위젯 표정·확인 표시를 사용하고 클릭하면 말풍선을 연다. 다른 프로그램의 포커스는 10분 궁극기에서만 명시적으로 전환한다.

일시정지·탭 전환·가림·관측 오류·긴 폴링 공백은 누적하지 않는다. 재생이 다시 관측되면 이전 실제 관측 시간에서 이어간다. 세션 종료·감지 동의 철회·AI 동의 철회는 타이머와 판단 캐시를 비운다. 오탐 정정 ID는 현재 세션에서만 유지한다. 궁극기 표시 직전에도 Rust에서 현재 작업 ID, 실행·일시정지 상태, 로컬 감지·YouTube 관측 동의와 연결 상태를 재확인한다.

자동 테스트는 가상 시간으로 59초, 1분, 5분, 10분 경계와 무응답·정정·동의 철회·숨김·중복 ID를 검사한다. 실제 Claude 호출 결과와 구분한다.

## 검증 명령

`frontend/`에서 `npm test`, `npm run build`, `node scripts/desktop.mjs check`, `node scripts/desktop.mjs test --lib`를 실행한다. `extension/`에서 `npm test`를 실행한다. 테스트용 API 주소·짧은 타이머·합성 데이터는 제품 설정으로 커밋하지 않는다.

## 이번 통합 검증 결과

- React 125개, Chrome 확장 12개, Rust 24개 테스트를 통과했다. React 빌드와 cargo check를 통과했고, 통합 소스의 Windows 디버그 앱을 빌드·실행했다.
- 실제 Windows에서 밝은 시작 화면, 한 줄 입력, 세션 생성 후 메인 숨김, 독립 위젯의 동일 작업명, 일시정지·재개·종료를 확인했다. 세션 API는 기존 FastAPI 로직을 사용하는 별도 메모리 DB와 로컬 모의 AI 서버로 실행했다. 기존 사용자 DB는 사용하지 않았다.
- 1·5·10분 단계, 무응답 시 자동 인정 방지, 오탐 정정 후 재질문 방지, 동의 철회, 종료 및 영상 숨김 처리는 가상 시간과 모의 판단 응답으로 검사했다. 유료 AI 호출은 수행하지 않았다.
- 실제 Windows의 영상 기반 단계 전환, 10분 궁극기의 전체화면 전환·복원, 실제 AI 판단은 미검증이다. 검증 앱의 로컬 감지 동의가 꺼져 있는 상태를 확인했으며, 자동으로 켜지 않았다. 이 항목은 사용자가 직접 각 동의를 설정한 뒤 짧은 개발 테스트로 확인해야 한다.
- Windows 실행 종료 시 WebView의 창 클래스 해제 오류 1412 로그가 한 차례 기록됐다. 이후 앱 실행과 세션 시작·종료는 가능했으나, 해당 종료 로그의 재현 원인은 미확정이다.
- 원래 작업 폴더의 리뷰 변경 4개와 backend·extension·browser.rs·visibility.rs는 이번 통합 커밋에 포함하지 않는다. 원격 push와 배포는 수행하지 않는다.
