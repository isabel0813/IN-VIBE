뭐보뇽 설치 안내

웹은 집중 세션 시작·종료와 계획 관리를 제공합니다. 독립 안뇽이와 YouTube 자동 관측은 Windows 11 앱과 Chrome 확장이 필요합니다.

Windows MVP 다운로드 (ZIP, 약 2.19 MB) · 시험판 검증 범위 확인

  1. ZIP 전체를 고정된 폴더에 압축 해제하고 Windows 설치 EXE를 실행합니다. 현재 배포 파일은 코드 서명되지 않았습니다. 제공 출처와 SHA256을 확인하세요.
  2. Chrome 주소창에 chrome://extensions를 입력하고 개발자 모드를 켠 뒤, 압축해제된 확장 프로그램 로드로 ZIP의 extension 폴더를 선택합니다.
  3. 확장 ID가 ohajfkkemocajnjlbnogdmoominkejci인지 확인합니다.
  4. ZIP 폴더에서 PowerShell을 열고 powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\extension\scripts\Configure-DownloadedHost.ps1로 등록 미리보기를 확인합니다. 동의하면 같은 명령 끝에 -Register를 붙여 실행합니다. 사용자별 HKCU의 호스트 키 하나를 등록합니다. 관리자 권한이나 Rust 설치는 필요하지 않습니다.
  5. 뭐보뇽 앱에서 공부할 일 한 줄을 입력합니다. AI 판단 동의, Windows 활동 관측 동의, YouTube 로컬 관측 동의를 확인하고 확장 팝업에서도 관측을 켭니다. YouTube 탭은 새로고침합니다.
  6. 집중 시작 후 일반 YouTube 영상을 재생합니다. AI가 확인을 요청하면 안뇽이에 작은 표시가 나타납니다. 직접 클릭하여 질문을 확인하고, 공부에 필요한 영상이면 “아니? 전혀~”로 정정합니다. 계획 보기에서 메인으로 돌아가 세션을 종료할 수 있습니다.

현재 지원 범위

선택된 일반 YouTube 탭과 실제 활성 Chrome 창을 확인합니다. Shorts는 미분류입니다. 화면 분할·듀얼 모니터에서 비활성 창의 재생을 함께 관측하는 기능과 다른 PC에서의 설치 검증은 후속 작업입니다. 창 제목과 YouTube DOM 변경에 따라 영상 관측이 제한될 수 있습니다.

영상 제목·ID는 AI 판단에 별도 동의한 집중 세션에서 운영 API로 전송합니다. 화면 캡처나 키 입력 수집은 하지 않습니다. 테스트 후 앱과 확장의 관측을 꺼 주세요.
