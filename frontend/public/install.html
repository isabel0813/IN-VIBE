처음 설치하는 순서

  1. 받은 ZIP을 오른쪽 클릭하고 모두 압축 풀기를 선택하세요.
  2. 집중 세션이 열려 있다면 종료한 뒤 앱과 Chrome을 닫으세요. Mobonyong-Tester-Beta-v2-Windows-x64-setup.exe를 실행하면 앱과 Chrome 연결 구성요소인 Native Host가 함께 설치돼요.
  3. Chrome 주소창에 chrome://extensions를 입력하고 오른쪽 위 개발자 모드를 켜세요.
  4. 압축해제된 확장 프로그램을 로드합니다를 누르고, 압축을 푼 폴더 안의 extension 폴더를 선택하세요. 로드한 폴더는 그 위치에 두세요.
  5. 시작 메뉴에서 Mobonyong Tester Beta를 열고, Chrome 퍼즐 메뉴의 안뇽이 · YouTube 공부 확인 팝업에서 앱 연결 표시와 관측 스위치를 확인하세요.
  6. 앱의 감지·AI 설정에서 Windows 활동 감지에 동의하고 적용한 뒤, YouTube 로컬 관측을 켜세요. AI 판단은 별개 동의이며, 동의하면 작업명과 영상 제목·ID가 판단을 위해 서버로 전송될 수 있어요.
  7. 공부할 일을 한 줄로 입력하고 집중 시작을 누르세요. 실제 제품은 Windows 무입력 또는 AI 판단 후 유효 영상 관측 시간이 각각 1·5·10분에 이르면 개입해요.

확장 연결과 업데이트

어떤 확장을 사용하나요?

동봉 확장은 0.3.6이며, chrome://extensions에서 개발자 모드를 켜면 항목의 ID ohajfkkemocajnjlbnogdmoominkejci를 확인할 수 있어요. Tester 앱 ID는 io.invibe.annyong.beta, Host는 io.invibe.annyong.youtube예요.

Chrome 웹 스토어판(ID nndjojfhmpbolfifcfdcpalcloanppod)과 발표용 DEMO 확장은 ID가 달라 Tester Host와 호환되지 않아요. 어떤 팝업을 열었는지 헷갈리면 Tester를 쓰는 동안 그 확장만 잠시 끄고, ZIP에 동봉된 항목을 사용하세요.

연결 대기나 영상 대기가 계속돼요

앱이 켜져 있고 동봉 확장의 관측 스위치가 켜져 있는지 확인하세요. 연결 대기가 계속되면 Chrome 메뉴에서 종료를 눌러 완전히 닫고 다시 여세요. 확장 폴더를 옮겼다면 현재 위치의 extension 폴더를 다시 로드하고, 설치 중 연결 오류가 있었다면 같은 계정에서 설치 EXE를 다시 실행하세요.

연결은 됐지만 영상 대기라면 집중 세션과 감지 동의를 확인하고, 화면에 보이는 선택된 탭에서 일반 YouTube 영상을 재생해 보세요. 광고나 일시정지 중에는 영상 시간이 쌓이지 않아요.

기존 Tester판을 업데이트하려면?

앱과 Chrome을 정상 종료하고, 같은 Windows 계정에서 기존 설치 경로를 유지해 새 EXE를 실행하세요. 앱 데이터 삭제 옵션이 나오면 선택하지 마세요. 기존 동봉 확장이 같은 ID로 작동하면 계속 쓸 수 있어요. 설치 후 Windows 활동 감지·YouTube 로컬 관측·AI 판단 설정을 각각 확인하세요.
