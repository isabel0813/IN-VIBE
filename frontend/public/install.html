처음 설치하는 순서

  1. ZIP을 받았다면 오른쪽 클릭하고 모두 압축 풀기를 선택하세요.
  2. 집중 세션이 열려 있다면 종료한 뒤 앱과 Chrome을 닫으세요. Mobonyong-Tester-Beta-v3-store-r1-Windows-x64-setup.exe를 실행하면 앱과 Chrome 연결 구성요소인 Native Host가 함께 설치돼요.
  3. Chrome 웹 스토어에서 안뇽이를 열고 Chrome에 추가를 누르세요. 개발자 모드나 수동 Host 등록은 필요 없어요.
  4. 시작 메뉴에서 Mobonyong Tester Beta를 열고, Chrome 퍼즐 메뉴의 안뇽이 · YouTube 공부 확인 팝업에서 앱 연결 표시와 관측 스위치를 확인하세요.
  5. 앱의 감지·AI 설정에서 Windows 활동 감지에 동의하고 적용한 뒤, YouTube 로컬 관측을 켜세요. AI 판단은 별개 동의이며, 동의하면 작업명과 영상 제목·ID가 판단을 위해 서버로 전송될 수 있어요.
  6. 공부할 일을 한 줄로 입력하고 집중 시작을 누르세요. Windows 무입력은 마지막 입력 이후 5·10·15분에 확인해요. YouTube는 AI 판단 후 유효 영상 관측 1·5·10분에 개입해요.

확장 연결과 업데이트

어떤 확장을 사용하나요?

공식 Chrome 웹 스토어판 0.3.2를 사용하세요. 확장 ID는 nndjojfhmpbolfifcfdcpalcloanppod예요. Tester 앱 ID는 io.invibe.annyong.beta, Host는 io.invibe.annyong.youtube예요.

이전 ZIP의 개발용 확장과 발표용 DEMO 확장은 새 Tester Host와 연결되지 않아요. 이전 개발용 확장이 켜져 있으면 해당 항목만 끄세요.

연결 대기나 영상 대기가 계속돼요

앱이 켜져 있고 공식 스토어 확장의 관측 스위치가 켜져 있는지 확인하세요. 연결 대기가 계속되면 Chrome 메뉴에서 종료를 눌러 완전히 닫고 다시 여세요. 설치 중 연결 오류가 있었다면 같은 계정에서 설치 EXE를 다시 실행하세요.

연결은 됐지만 영상 대기라면 집중 세션과 감지 동의를 확인하고, 화면에 보이는 선택된 탭에서 일반 YouTube 영상을 재생해 보세요. 광고나 일시정지 중에는 영상 시간이 쌓이지 않아요.

기존 Tester판을 업데이트하려면?

앱과 Chrome을 정상 종료하고, 같은 Windows 계정에서 기존 설치 경로를 유지해 새 EXE를 실행하세요. 앱 데이터 삭제 옵션이 나오면 선택하지 마세요. 같은 0.3.8이 설치되어 있다면 다시 설치를 선택하세요. 설치 후 Windows 활동 감지·YouTube 로컬 관측·AI 판단 설정을 각각 확인하세요.

베타 검증 범위

공식 확장으로 실제 YouTube 영상이 앱에 전달되어 말풍선까지 표시되는 전체 흐름과 듀얼 모니터 동작은 미검증이에요. 현재 스토어 확장은 PiP 관측을 지원하지 않아요.
