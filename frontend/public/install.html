뭐보뇽 Windows 0.3.2 설치 안내

웹의 한 줄 세션과 Windows의 독립 위젯·Chrome 관측은 서로 다릅니다. 자동 업데이트 대신 새 GitHub Release ZIP을 받아 설치합니다.

Windows ZIP 다운로드 · 검증 범위·SHA256

  1. ZIP과 SHA256SUMS.txt를 비교하고 전체를 압축 해제하세요. 기존 앱을 정상 종료한 후 설치 EXE를 같은 설치 경로에서 실행합니다. 사용자 데이터 삭제를 선택하지 마세요. 설치 파일은 코드 서명되지 않았으므로 출처와 해시를 확인하고 설치 여부를 직접 결정하세요.
  2. 동봉 개발용 확장은 chrome://extensions에서 extension 폴더를 로드합니다. ID는 ohajfkkemocajnjlbnogdmoominkejci입니다. 공식 웹 스토어 ID nndjojfhmpbolfifcfdcpalcloanppod와 다릅니다.
  3. ZIP 루트에서 powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\extension\scripts\Configure-DownloadedHost.ps1 -ExtensionId ohajfkkemocajnjlbnogdmoominkejci로 미리 확인하세요. 승인 후 같은 명령에 -Register를 붙이면 검증된 Host를 LOCALAPPDATA의 고정 경로로 복사하고 HKCU 등록을 백업·갱신합니다. 기본 ID는 웹 스토어판이므로 개발용은 반드시 ID를 명시하세요.
  4. 확장을 다시 로드하고 YouTube 탭을 새로고침하세요. 앱의 로컬 활동 감지·YouTube 관측과 확장 관측을 사용자가 직접 켭니다. 집중 시작 전은 대기, 실행 후는 영상 대기 또는 관측 중이 기대 상태입니다.
  5. AI 판단은 별도 동의 후 작업명·영상 제목·ID를 운영 API로 보내며 유료 호출이 생길 수 있습니다. AI 동의 없이도 세션과 로컬 연결을 확인할 수 있습니다. 실제 관측 누적 1·5·10분 개입이며 첫 질문은 위젯을 클릭해 확인합니다.

Shorts는 미분류입니다. 실제 AI E2E·실영상 1/5/10분·궁극기·다른 PC·듀얼 모니터 검증 범위는 Release 설명을 확인하세요. 모의 테스트 통과를 실제 관측 성공으로 보지 않습니다. 상세 설치·해제·롤백은 ZIP의 README.md를 따르세요.
