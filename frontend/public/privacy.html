처리하는 정보와 목적

기기에서 생성한 임의 사용자 ID, 집중할 일, 세션 시작·종료 시각, 영상 식별값의 해시와 분류·정정 결과 및 사유, 서비스 이용 이벤트를 집중 지원과 사용자 검증 통계에 사용합니다. 기존 할 일 기능의 이름·마감·완료 기록과 사용자 설정도 저장될 수 있습니다. 임의 ID는 기기별 이용 기록을 구분하기 위한 식별자이며, 실명 인증 정보는 아닙니다.

Windows 로컬 활동 감지에 동의하면 활성 창의 프로세스 이름·제목과 활동 시간을 기기에서 처리합니다. YouTube 로컬 관측에 별도로 동의하면 선택된 YouTube 탭의 영상 제목·영상 ID·재생 상태, 탭·창의 활성 및 표시 상태와 관측 시간을 Chrome 확장 → Native Messaging Host → Windows 앱으로 전달합니다. 이 로컬 전달 자체는 외부 서버 전송이 아닙니다.

Chrome 확장은 YouTube 페이지에만 접근하며, 전체 방문 이력, 키 입력, 화면 캡처, 영상 본문·음성, YouTube 계정이나 비밀번호를 수집하지 않습니다. 관측 정보는 공부 관련성 확인과 복귀 안내에 사용하며 판매하거나 맞춤형 광고에 사용하지 않습니다. Chrome 웹 스토어 사용자 데이터 정책의 제한적 사용 요건에 따라 사용자에게 제공하는 집중 지원 기능에 필요한 범위에서만 처리합니다.
